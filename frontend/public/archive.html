怎么换成你自己的表情包
把 PNG / JPG / GIF / WebP / APNG 放进 dist/archive/media/， 然后在 dist/archive/media.json 的 items 里登记 { "file": "media/xxx.png", "title": "标题", "tag": "标签" }。 动图（GIF / WebP / APNG）会自动播放。留空时本页展示内置原创示例贴纸， 不预置任何第三方表情包。投稿方式：把图片放进仓库 media/ 后发 Pull Request，或直接提 Issue 附图片。
